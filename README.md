# 胶片相机助手

一个离线可用的 PWA，给胶片用户在拍摄现场查参数、算曝光用。

## 为什么做这个

胶片相机没有屏幕回放，参数错了要等冲洗才知道。而现场能查的东西太少：
机身背面那张褪色的曝光表、手机里翻半天找不到的笔记。

这个工具把三件事放在一屏里：**这卷胶片的脾气**、**当前光线该用什么参数**、**想换个拍法怎么换算**。

## 三块功能

### 1. 胶片参考卡片

黑白负片 / 彩色负片（C-41）/ 反转片（E-6）三类，各自的：
- 常见 ISO 档位
- 过曝欠曝的容错范围（黑白 ±2~3 级，反转片只有 ±0.5 级）
- 典型场景的光圈快门推荐

### 2. 测光

- **阳光16 计算器**：选天气，直接给光圈快门组合
- **安全快门**：按焦距算手持下限，低于它提醒你靠墙或上脚架
- **环境光传感器**：安卓 Chrome 可读真实照度，出 EV 与推荐组合
- **摄像头测光**：拿不到 ISP 元数据，只作示意，界面上明确标注了

### 3. 等效曝光换算（`src/ev-swap.js`）

站在现场最常问的一句：**「同样是这个亮度，换个光圈怎么拍？」**

选定光圈 / 快门 / ISO 后：
- 实时显示 EV（ISO100 基准）
- 改任一个参数，另一个自动补回来 —— 亮度不变，景深或动感改变
- 列出当前亮度下所有可用的「光圈 × 快门」组合，并高亮你正在用的那格
- 提示安全快门、长曝光倒易律、高 ISO 颗粒

数学部分：

```
EV100 = log2(N² / t) − log2(ISO / 100)
t     = N² / 2^(EV + log2(ISO / 100))
```

`N` 是光圈 f 值，`t` 是快门秒数。

## 离线

Service Worker 用 stale-while-revalidate：先给缓存秒开，后台拉新版。
胶片用户常在没信号的地方查参数，离线能力是这个工具的主要价值，不是加分项。

预缓存清单漏一个文件，离线时页面就会缺样式或不能点。`sw.js` 里的
`PRECACHE` 数组必须和实际文件一一对应。

## 开发

无构建步骤，改完直接刷新即可。纯静态文件：

```
index.html              骨架
src/app.css             样式
src/app.js              卡片、测光、传感器逻辑
src/ev-swap.js          等效曝光换算（纯函数，可单独 require 测试）
sw.js                   Service Worker
manifest.webmanifest    PWA 清单
```

`src/ev-swap.js` 不碰 DOM，可以直接在 Node 里验证：

```js
const E = require('./src/ev-swap.js');
E.evOf(8, 1/125, 400);        // 10.966
E.shutterFor(10.966, 4, 400);  // 1/500
```
